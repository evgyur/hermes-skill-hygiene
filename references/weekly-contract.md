# Weekly maintenance contract

Provision one job in the existing scheduler only after explicit authorization. Resolve the timezone and exact private delivery origin from trusted runtime metadata; never use a shared team sender or default home channel for private reports.

1. Collector: resolve current managed runtime, collect all admitted profile catalogs, deduplicate realpaths, audit admitted Markdown and compare the source/config/alias signature with the last successful verified state. Do not expose document text or secrets in scheduler stdout.
2. Unchanged: exit using the scheduler's native no-op/suppression outcome. Never reset pending work or label unreadable/failed collection healthy.
3. Changed: load the installed skill and inspect only the changed scope plus its dependencies. Perform bounded authorized document maintenance through native/source owners. Retain unique procedures and protection gates. No deletion, blanket disabling, runtime/provider/auth changes, source-owner bypass, purchases, public publishing or extra workers.
4. Guard: conflict, permission failure or protected effect becomes a precise held item, not an alternate-method write. Record pending findings and avoid retry loops. A hash-bound reviewed historical/template/source-bound exception remains visible; it is not a claim that the material is healthy.
5. Verify: run the affected structural/mutation checks and both profile consumers. Recompute the final catalog/audit after the last edit. Advance last-successful state only after this evidence exists; retain a failed run's previous successful state.
6. Deliver: return a compact result to the exact authorized origin, with counts and exceptions, or remain silent when nothing changed. Verify persisted job fields, first scheduler execution and exact delivery/suppression. Do not equate a manual script run with a scheduled agent run.

The public repository contains no particular user's job, selectors, chat IDs, runtime paths or review exceptions. Those belong in access-controlled operator state. Do not commit private audit JSON, original skill text, receipts, configuration or weekly output here.
